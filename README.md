# **lcd-smartie-amdgpu**

# Description:
Outputs AMD GPU performance stats (using ADL).

# Formatting:
$dll(AMDGPUStats,[stat],,)

# Clarification:
[stat] = 1 ⟶ GPU Temp (C)  
[stat] = 2 ⟶ GPU Load (%)  
[stat] = 3 ⟶ Fan Speed (RPM)  
[stat] = 4 ⟶ GPU Power Consumption (W)  
[stat] = 5 ⟶ Core Clock (MHz)  
[stat] = 6 ⟶ Memory Clock (MHz)  
[stat] = 7 ⟶ Dedicated VRAM Usage (MB)  
[stat] = 8 ⟶ GPU Core Voltage (V)  
[stat] = 9 ⟶ # of AMD GPUs
